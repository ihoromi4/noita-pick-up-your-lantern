# Developer Documentation

Technical documentation for contributors to the **Pick Up Your Lantern** mod for Noita: how the mod is built, which engine quirks it works around, and why. For what the mod does from the player's point of view, see the [Player Guides](../guides/README.md).

- [Architecture](architecture.md): mod layout, startup patches, frame hooks, entity scripts, item lifecycle tags and helper libraries.
- [Lantern Entities](lantern-entities.md): pickable lantern entities, the physics system, ceiling anchors, sprite geometry, other light sources, hanging ropes, the tube lamp cable, lantern chains and chain torches.
- [Holding and Belt](holding-and-belt.md): in-hand sprites, mirroring, swinging, the flame desync fix and the belt lantern.
- [Throwing](throwing.md): throw setup, hanging on the left mouse button, flight physics, shattering and engine limitations.
- [Lantern Properties and Progression](lantern-properties-and-progression.md): base properties per type, quality tiers, modifiers, liquid states and the item description.
- [Vision and Lighting](vision-and-lighting.md): limited vision shader patch, vision presets, polymorph, the All-Seeing Eye, glowing materials and the fire enemy glow.
- [Creatures and Light](creatures-and-light.md): light sources, the visibility API, luring enemies to lanterns and Natural Fear.
