# Development Roadmap

Development roadmap and release milestones for the **Pick Up Your Lantern** mod for Noita. Detailed functional specifications for each feature are documented in [requirements.md](requirements.md).

## Version 0.1 - MVP and Core Lifecycle

Version 0.1 delivers a fully functional, stable core gameplay loop for standard hanging oil lanterns: world physics and ceiling anchors, pickup into `Quick Inventory`, holding in hand with swaying light, throwing with shattering and oil fires, and configurable limited player vision. Features and implementation details: [version-0.1.md](versions/version-0.1.md).

## Version 0.1.1 - Item Radar Fix

Version 0.1.1 is a patch release that hides lanterns from the Item Radar perk, with a Mod Settings toggle to show them. Details: [version-0.1.1.md](versions/version-0.1.1.md).

## Version 0.2 - Passive Carrying and Atmosphere

Version 0.2 focuses on passive utility and atmospheric carrying mechanics: a lantern on the belt that lights the way while hands are busy, distinct lantern properties with quality tiers and rare modifiers, oil-soaked and wet states, and vision fixes for polymorph, chain torches and All-Seeing Eye. Details: [version-0.2.md](versions/version-0.2.md).

## Version 0.3 - Variety and World Interactions

Version 0.3 expands the scope to other light fixtures and world interactions: pickable chain torches, mining lamps, temple lanterns and tube lamps, hanging a held lantern on the ceiling, enemy study, the cracked glass modifier and combined modifiers, settings presets, brighter fire enemies drawn to lanterns, and the Natural Fear mode. Details: [version-0.3.md](versions/version-0.3.md).

## Version 0.3.1 - Lantern Modifier Hotfix

Version 0.3.1 is a hotfix release that makes lantern modifiers work again and fixes a memory leak that slowed down the game and its closing. It also cleans up saves made with version 0.3. Details: [version-0.3.1.md](versions/version-0.3.1.md).

## Version 0.4

> **Not ready yet**: this version is still in development and has not been released.

Version 0.4 adds modifiers specific to the new light fixtures (temple lanterns filled with magic liquids), open-flame torches and braziers that set things on fire, the Rogue mode that hides the player in darkness, and redesigned UI icons. Details: [version-0.4.md](versions/version-0.4.md).

## Version 1.0 - Polished State Simulation

> **Not ready yet**: this version is still in development and has not been released.

Version 1.0 delivers complete physical and chemical state transitions and release stability: lanterns go out under liquid and show as unlit, react to other liquids and light again from fire, the game can be finished at the darkest vision presets with a light source in every biome, and the final balance, performance and compatibility pass. Details: [version-1.0.md](versions/version-1.0.md).
