# Documentation

Welcome to the documentation of **Pick Up Your Lantern**, a Noita mod that lets you pick up, hold, carry, and throw lanterns. This page lists the main documents of the project.

## Contents

- [Where to Start](where-to-start.md): Follow a reading path based on your goal as a player, contributor, or release maintainer.
- [Player Guides](guides/README.md): Read how lanterns, the belt lantern, lantern quality, creatures in lantern light, limited vision, and Mod Settings work in the game. This section is for players.
- [Developer Documentation](dev/README.md): Read about the architecture, engine quirks, and implementation details. This section is for contributors.
- [Functional Requirements](requirements.md): Read the full feature specification of what the mod is meant to do. This document is for contributors and designers.
- [Development Roadmap](roadmap.md): Check planned features grouped by release. This document is for everyone.
- [Backlog](backlog.md): Check tasks that are not done yet, grouped by topic. This document is for contributors.
- [Versions](versions/README.md): Check the list of releases, what each version delivered, and which issues were fixed. This section is for everyone.
