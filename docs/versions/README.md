# Versions

This folder lists the versions of **Pick Up Your Lantern** and the work that belongs to each of them. Planned tasks and open work live in the [Backlog](../backlog.md).

## Rules

- Describe each completed task in one to three sentences in the notes of the version that includes it.
- The version notes live in the `version-X.Y.Z.md` files. Put the description under `Completed Work` or under a section for its topic.
- If the version has no notes file yet, create it with the first completed task. Add the new file to the [Version List](#version-list).

## Version List

- [0.4.0](version-0.4.0.md): In progress. Adds diffused bluish air ambient light with softened silhouettes in Snowy Depths and Hiisi Base, dries wet oil lanterns in fire and hot biomes, limits liquid states to oil lanterns, adds a 1-second submersion timer with fire reactions and sounds for chain torches, exports a visibility API, and moves Enemy Study to In Game Wiki.
- [0.3.2](version-0.3.2.md): All-Seeing Eye lifetime fix. Scales the All-Seeing Eye reveal time with projectile lifetime modifiers, holds the reveal near the cast point, and removes the temporary save cleanup.
- [0.3.1](version-0.3.1.md): Lantern modifier hotfix. Restores the lantern modifier script, fixes the memory leak on lanterns with modifiers, and adds temporary save cleanup for version 0.3.0.
- [0.3.0](version-0.3.0.md): Variety and world interactions. Adds pickable chain torches, mining lamps, temple lanterns, and tube lamps, ceiling hanging, Enemy Study, Cracked glass, settings presets, fire enemy glow and luring, and Natural Fear.
- [0.2.0](version-0.2.0.md): Passive carrying and atmosphere. Adds the belt lantern, quality tiers, rare modifiers, liquid states, and vision fixes for polymorph, chain torches, and the All-Seeing Eye.
- [0.1.1](version-0.1.1.md): Item Radar fix. Hides lanterns from the Item Radar perk by default, with a Mod Settings toggle to show them.
- [0.1.0](version-0.1.0.md): MVP and core lifecycle. Adds pickable hanging oil lanterns, holding, throwing, dynamic lighting, and limited player vision.
